# From-Detection-to-Localization-A-Unified-Forensics-Framework-for-Fully-Synthetic-and-Tampered-Images
This repository contains the implementation associated with our paper "From Detection to Localization: A Unified Forensics Framework for Fully Synthetic and Tampered Images", which has been accepted at the ACM Multimedia 2026 Workshop on DeepFake Forensics (DFF). The source code and instructions for reproducing the experiments will be released soon.
